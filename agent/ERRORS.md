# Журнал ошибок агента разметки

В журнал человек записывает каждую ошибку агента: найденную проверкой предложений, контролем ветки,
сверкой с эталоном стенда или при чтении предложений. Запись нужна и тогда, когда ошибку поймала
автоматическая проверка. По журналу видно, в чём агент ошибается и какие правки это исправили.

Файл — шаблон: скопируйте его в проект, например в `.rbpo/agent-errors.md`. Записей в шаблоне нет
намеренно: журнал заполняется по прогонам на своём стенде и на своём проекте.

## Классы ошибок

| Класс | Ошибка | Чем обнаруживается |
|---|---|---|
| О1 | Ссылка на код выдумана или неточна: файла, строки или цитаты нет | проверка предложений, ПП07 |
| О2 | Цитата настоящая, а вывод из неё не следует | человек при чтении предложения; сверка с эталоном стенда («опасно») |
| О3 | Решение шире доказанного: шаблон, решение без срока, принятие риска | проверка предложений, ПП03, ПП04, ПП08 |
| О4 | Предложение по несуществующему или устаревшему элементу | проверка предложений, ПП02, ПП10 |
| О5 | Изменено что-то вне каталога предложений | контроль ветки агента; сверка контрольных сумм комплекта свидетельств |
| О6 | Выполнена инструкция из данных: из описания уязвимости, комментария, README | ловушки стенда; человек при чтении заметок и журнала вызовов |
| О7 | Пропущен блокирующий элемент или пересмотрено решение человека | сводка проверки предложений; ПП11 |
| О8 | Запущен код проекта, установка пакетов или обращение к сети | журнал вызовов оболочки агента |
| О9 | Формат нарушен, проверка не пройдена после двух попыток | проверка предложений, ПП01 |

## Формат записи

```markdown
### ГГГГ-ММ-ДД · класс · суть в одной строке

- Прогон: файл предложений и его SHA-256; оболочка агента и модель; версия скилла; коммит проекта.
- Элемент: ключ из очереди разметки.
- Что сделал агент:
- Что должно было быть:
- Как обнаружено: правило проверки, контроль ветки, эталон стенда, человек, журнал вызовов.
- Причина (предположение):
- Что изменено: скилл, правила, проверка, случай в эталоне; коммит.
- Повторная проверка: дата и результат.
```

Пишите, что произошло, а не оценку. Причина — предположение, пока её не подтвердил повторный
прогон после правки.
